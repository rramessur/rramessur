Application Instructions

How to use the PDF Extractor, Generator, and Matcher tools.

Note: After a period of inactivity, the website may take one to two minutes to start up. These applications only work with machine-readable PDFs (e.g. the online GOS-18 form). They will not work with electronically completed but non-machine-readable PDFs, or with handwritten forms.

  1. Navigate to the App: You will see tabs corresponding to different applications.
  2. PDF Data Extractor: If you already have sample PDFs and would like to extract their fields into a CSV file, use the “PDF Data Extractor” tab.
  3. Handling CSVs in Excel:

    Be aware that although the extracted CSV is initially formatted correctly, Excel will convert fractions (e.g. 6/6) into dates if the file is edited and saved. To prevent this, follow the steps below:

    1. Open Excel
    2. Go to Data → From Text/CSV
    3. Select your .csv file
    4. In the preview window:
      1. Click Transform Data
      2. Select the six VA columns: PinholeLeft, PinholeRight, Previous corrected VA on dateLeft, Previous corrected VA on dateRight, VALeft, VARight
      3. Set Data Type → Text
      4. If you intend to use clinical data only (e.g. to match against a separate patient dataset), this is a good point to remove columns like: Date of Birth, Gender, NHS number, Px Address, Px Forename, Px Post Code, Px Surname, Px Telephone, Px Title.
      5. Click Close & Load
    5. Save the resulting file as a CSV (not an Excel workbook).
  4. PDF Generator: This application has three upload areas:
    1. Demographics CSV – upload a CSV containing patient demographics only. The column headers must match the field names in the GOS-18 form.
      • If you are using a different machine-readable PDF, you will need to manually update the column headers to match your PDF's fields.
    2. Clinical Details CSV – upload the clinical data generated using the PDF Data Extractor.
    3. Template PDF – upload the PDF template (e.g. the sample GOS-18 form).
    4. Click “Generate PDF & Download ZIP”. The app will generate PDFs with demographic data randomly merged with clinical data.
      • Note: In approximately 30% of generated PDFs, fields like NHS number, Gender, Address, or Postcode will be randomly missing.
  5. Direct Fill PDF: If you already have a single merged CSV containing both demographic and clinical data, you can use “Direct Fill PDF” instead. Upload your CSV and the template PDF, and the fields will be auto-filled (again with ~30% missing demographic data logic applied).
  6. Patient Matcher AI: If you would prefer to merge the demographic and clinical CSV files as a separate step before using “Direct Fill PDF”, upload both files to the “Patient Matcher AI” app. This will generate a merged CSV for you.
